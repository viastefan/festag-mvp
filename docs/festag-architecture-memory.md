# Festag Architecture Memory

**Locked product surface.** The Operating System remembers *why* it was built — not only *what*.

**Code:** `lib/architecture/`  
**UI:** `/architecture`  
**Cursor guardian:** `.cursor/rules/festag-architect-ai.mdc`

Supreme with: Product Constitution · Architecture Confirmation · Experience · Identity · Adaptive Intelligence.

---

## Why this exists

Festag is not a feature pile. It is a self-consistent product ecosystem.

Ideas must not get lost in Cursor chats or undocumented refactors. Every structural decision needs a durable reason so Tagro Architect, humans, and future agents can check new work against the OS — not against vibes.

## Two agents (never collapse)

| Agent | Job |
|---|---|
| **Tagro** | Quiet COO of the *workspace* — mediates delivery, status, decisions, OKM |
| **Festag Architect AI (Tagro Architect)** | Hüter of the *platform* — vision, constitutions, design system, schema, pricing, AI rules |

Architect gates **before** code. Tagro operates **inside** the product.

## Architecture module (`/architecture`)

First-class rail surface (not buried in Settings). Sections:

1. **Vision** — north star and positioning  
2. **Product Constitution** — master prompts / laws  
3. **Design System** — tokens, spacing, radius, motion, shadows  
4. **Database** — tables, relations, policies  
5. **APIs** — OpenAI, Claude, GitHub, Stripe, Google, Apple, …  
6. **AI Rules** — Tagro · Developer lens · Client lens  
7. **Workspace Rules** — Agency · Startup · Enterprise · Solo · …  
8. **Business Rules** — pricing, limits, plans, seats, AI / developer budget  
9. **Roadmap** — what comes next  
10. **Feature Requests** — ideas not yet built, prioritized, status  
11. **Technical Debt** — calm, evidence-backed refactor signals  
12. **Production Intelligence** — Tagro Superintelligence pillar for digital production (architecture reserved: `docs/festag-production-intelligence.md`). Not a dashboard. Not token vanity. Not Auto Mode.  
13. **Architecture Memory** — decisions + reasons (this doc’s heart)  
14. **Architecture History** — versioned decision log (“git for decisions”)

## Architecture Memory

Each entry answers:

- **Question** — e.g. “Warum gibt es keinen Dev Login?”  
- **Answer** — calm reason  
- **Decision** — date + architecture version  
- **Status** — `locked` · `evolving` · `superseded`

Example:

> Warum gibt es keinen Dev Login?  
> Weil Workspace modular aufgebaut wird — eine Auth-Erfahrung, Rollen als Linsen.  
> Entscheidung: Universal Login · Version 2.2 · locked

## Architecture Status

Calm health of the OS domains (Vision, UX, Database, APIs, Design, AI, Pricing, Workspace, Roadmap, Production, Architecture, Memory).

Surfaced on `/architecture` and as a compact status affordance for builders.

## Production + Workspace Intelligence

Production Intelligence is a **Tagro Superintelligence** pillar (see `docs/festag-production-intelligence.md`) — operational intelligence for digital production, architecture reserved. It lives in the OS map as a modular workspace capability, not as a disconnected admin toy or token dashboard.

Workspace Intelligence (healthy workspace, budget %, AI spend, delivery score, …) is the *runtime* twin: company/workspace truth. Architecture Memory is the *platform* twin: Festag’s own DNA.

## Gate

Before shipping features that change product shape:

1. Architect gate passed?  
2. Memory entry needed or updated?  
3. History version bump needed?  
4. Constitutions still true?  
5. No dual-product regression?

If “feature without why” — write the Memory entry first.
